# طوطی آرا — پنل مدیریت آنلاین رایگان

این نسخه از Supabase برای ذخیره آنلاین محصولات استفاده می‌کند و روی GitHub Pages قابل میزبانی است.

## راه‌اندازی

1. یک پروژه رایگان در Supabase بساز.
2. داخل SQL Editor محتوای `supabase.sql` را اجرا کن.
3. در Authentication > Users یک کاربر مدیر بساز؛ ایمیل و رمز همین پنل خواهد بود.
4. از Project Settings > API مقدار Project URL و anon public key را بردار.
5. در `supabase-config.js` دو مقدار را جایگزین کن.
6. هر چهار مورد `index.html`، `admin.html`، `supabase-config.js` و پوشه `assets` را داخل مخزن GitHub قرار بده.
7. سایت را باز کن. از منوی «مدیریت» وارد پنل شو.
8. اضافه/حذف محصول از پنل، در دیتابیس ذخیره می‌شود و برای همه بازدیدکنندگان سایت نمایش داده می‌شود.

نکته امنیتی: رمز عبور در کد سایت قرار داده نشده است. `anon key` عمومی است و امنیت نوشتن اطلاعات با Row Level Security در `supabase.sql` انجام می‌شود.
