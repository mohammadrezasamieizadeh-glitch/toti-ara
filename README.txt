سالن پرورش طوطی آرا — بسته وب‌سایت

راه‌اندازی سریع
1) همه فایل‌های ZIP را در یک پوشه یا روی میزبانی وب استخراج کنید.
2) index.html را در مرورگر باز کنید. برای مسیرهای مطلق و قابلیت‌های مرورگر بهتر است فایل‌ها را روی میزبانی ایستا (HTTPS) قرار دهید.
3) برای مدیریت فهرست، روی «مدیریت سایت» یا «پنل مدیریت» بزنید و admin.html را باز کنید.
4) رمز پیش‌فرض پنل: 0216d7c3
5) افزودن/ویرایش عکس و طوطی به صورت پیش‌فرض در localStorage مرورگر ذخیره می‌شود؛ اطلاعات فقط در همان مرورگر/دستگاه در دسترس است. برای تصاویر بزرگ، عکس کم‌حجم انتخاب کنید.
6) supabase-config.js و supabase.sql برای راه‌اندازی اختیاری Supabase ارائه شده‌اند. URL و anon key پروژه را در فایل تنظیمات قرار دهید و schema را در SQL Editor اجرا کنید. برای امنیت واقعی، مجوزهای نوشتن باید از سمت سرور/سیاست‌های احراز هویت کنترل شوند.

فایل‌ها
- index.html: سایت فارسی، دسته‌بندی‌ها، ناوبری/لینک‌های سریع و پنجره دسترسی مدیریت
- admin.html: پنل افزودن/ویرایش/حذف پرندگان، دسته‌بندی و آپلود عکس
- hero.png: تصویر اصلی سایت
- supabase-config.js و supabase.sql: کمک‌کد و طرح‌واره اختیاری Supabase

نکته امنیتی: رمز پنل در فایل جاوااسکریپت سمت مرورگر قرار دارد و صرفاً برای دسترسی ساده به رابط است؛ حفاظت واقعی اطلاعات با این رمز انجام نمی‌شود. برای استفاده عمومی/تولیدی، پنل را به احراز هویت امن سمت سرور متصل کنید.
