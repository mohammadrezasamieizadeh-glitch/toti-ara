راهنمای راه‌اندازی سایت آرا
=============================

این بسته کاملا مستقل و از صفر نوشته شده است و برای نمایش خانه فقط از hero.png استفاده می‌کند.

ترتیب راه‌اندازی
1) در Supabase یک پروژه بسازید.
2) فایل supabase.sql را کامل در SQL Editor قرار دهید و Run کنید. این فایل جدول‌ها، RLS، سیاست‌ها، باکت product-images و داده‌های اولیه سه گونه را می‌سازد.
3) در Authentication > Users یک کاربر مدیر بسازید (ایمیل و رمز عبور).
4) در supabase-config.js مقدار url را با آدرس پروژه و anonKey را با کلید عمومی anon پروژه جایگزین کنید. کلید service_role را هرگز در این فایل نگذارید.
5) برای تست محلی، پوشه را با یک وب‌سرور ساده باز کنید؛ مثلا در همین پوشه `python -m http.server 8080` و سپس `http://localhost:8080`.

استقرار با GitHub Pages
1) هفت فایل همین پوشه را در ریشه یک repository جدید قرار دهید: index.html، admin.html، supabase-config.js، supabase.sql، README.txt، preview-notes.txt و hero.png.
2) در Settings > Pages شاخه اصلی و پوشه root را انتخاب کنید و ذخیره بزنید.
3) پس از انتشار، دامنه GitHub Pages را در Supabase Authentication > URL Configuration به عنوان Site URL و Redirect URL ثبت کنید.

استفاده از پنل
admin.html را باز کنید، با کاربر Supabase وارد شوید و محصول را بسازید یا با دکمه ویرایش اصلاح کنید. حذف محصول و حذف تصویر گالری هم در همان صفحه انجام می‌شود. انتخاب فایل تصویر پیش‌نمایش محلی دارد و پس از ذخیره به Storage باکت product-images می‌رود.

تغییرات محتوا از طریق پنل انجام می‌شود و برای آن نیازی به GitHub یا ویرایش فایل‌های سایت نیست. اجرای دوباره SQL داده‌های seed را با ON CONFLICT DO NOTHING بازنویسی نمی‌کند.

نکته امنیتی: RLS دسترسی نوشتن را فقط به کاربران authenticated می‌دهد. برای محدودیت‌های مدیریتی دقیق‌تر می‌توانید بعدا نقش‌های جداگانه تعریف کنید.
