انتشار:
۱. همهٔ فایل‌های ریشهٔ پوشهٔ V3 را در ریشهٔ مخزن GitHub Pages آپلود کنید؛ فایل‌ها را داخل پوشهٔ دیگری نگذارید و خود ZIP را آپلود نکنید.
۲. صبر کنید deployment گیت‌هاب کامل شود.
۳. در موبایل و دسکتاپ hard refresh انجام دهید یا cache سایت/مرورگر را پاک کنید.
۴. سایت عادی را با index.html آزمایش کنید و مسیرهای گالری و تماس را باز کنید.
۵. برای تشخیص اتصال، آدرس سایت را با ?supabase-test=1 باز کنید؛ یک پنل فشردهٔ فارسی وضعیت تنظیمات، آنلاین بودن مرورگر، میزبان و نتیجهٔ fetch را نشان می‌دهد.

رفتار گالری:
- صفحهٔ عمومی ابتدا از SDK رسمی Supabase در صورتی که از قبل در دسترس باشد استفاده می‌کند؛ در غیر این صورت، REST داخلی با fetch استفاده می‌شود و به CDN وابسته نیست.
- درخواست REST حداکثر ۱۰ ثانیه منتظر می‌ماند. خطاهای فنی فقط با پیشوند [Toti Ara gallery] در Console ثبت می‌شوند و به مشتری نمایش داده نمی‌شوند.
- در قطع شبکه، modal گالری پیام فارسی دوستانه و تماس تلفنی ۰۹۱۰۷۴۸۸۰۱۳ و واتساپ را نشان می‌دهد. کارت‌های داده‌شده نیز با عنوان و توضیحات ثبت‌شده و همین راه‌های تماس باز می‌شوند؛ بارگذاری تصویر راه دور ادعا نمی‌شود.
- اگر self-test نتواند به Supabase برسد، مشکل شبکه/DNS/فیلترینگ است و با HTML ایستا در GitHub قابل تعمیر نیست. VPN یا شبکهٔ دیگر فقط برای آزمایش تشخیصی است، نه راه‌حل سایت.

امنیت:

فایل‌های hero.png، supabase.sql و preview-notes.txt حفظ شده‌اند و هیچ تصویر جدیدی اضافه نشده است.
