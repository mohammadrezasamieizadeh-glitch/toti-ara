راهنمای استقرار طوطی آرا (Worker Architecture)
===================================================

۱. صفحه اصلی (index.html):
   - داده‌های گالری و پرندگان را به صورت کاملاً پویا فقط و فقط از Cloudflare Worker دریافت می‌کند.
   - آدرس اندپوینت ورکر:
     https://toti-ara-gallery.mohammadrezasamieizadeh.workers.dev/api/gallery
   - هیچ‌گونه کلید یا کتابخانه Supabase در index.html لود نشده است تا امنیت و سرعت حداکثری تضمین شود.

۲. بخش پنل مدیریت (admin.html):
   - از اتصال مستقیم به Supabase برای ثبت، ویرایش، حذف پرندگان و آپلود تصاویر استفاده می‌کند.
   - تنظیمات و آدرس دیتابیس در supabase-config.js و اسکریپت ساخت جدول در supabase.sql قرار دارد.

۳. فایل تصویر اصلی:
   - فایل hero.png باید حتماً در ریشه (Root) پروژه و کنار index.html قرار داشته باشد.

۴. نحوه دیپلوی:
   - تمامی فایل‌های اکسترکت‌شده از این زیپ را به صورت مستقیم در مخزن GitHub Pages یا سرور استاتیک خود آپلود و مستقر نمایید.
